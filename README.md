# Data Immersion & Wrangling Project

## Project Title
Data Immersion & Wrangling using Python (Pandas)

## Objective
The objective of this project is to perform data immersion, cleaning, and transformation on a raw dataset to prepare it for analysis. This includes handling missing values, removing duplicates, standardizing data formats, and creating new features.

## Dataset Used
* Iris Dataset (from seaborn GitHub repository)

## Steps Performed
* Loaded dataset using Pandas
* Performed initial data exploration
* Checked for missing values and duplicates
* Removed duplicate records
* Renamed and standardized column names
* Performed feature engineering (created PetalCategory)
* Exported cleaned dataset for analysis

## Tools Used
* Python
* Pandas
* NumPy
* Google Colab
* GitHub

## Output
A cleaned and analysis-ready dataset was generated successfully and saved as `cleaned_data.csv`.

## Outcome
This project helped in understanding real-world data preprocessing techniques which are essential before performing any data analysis or machine learning tasks.
