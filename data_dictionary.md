# Data Dictionary

| Column Name   | Data Type | Description              |
| ------------- | --------- | ------------------------ |
| SepalLength   | Float     | Length of sepal          |
| SepalWidth    | Float     | Width of sepal           |
| PetalLength   | Float     | Length of petal          |
| PetalWidth    | Float     | Width of petal           |
| Species       | String    | Flower species           |
| PetalCategory | Category  | Categorized petal length |
